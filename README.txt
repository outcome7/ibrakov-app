IBRAKOV — 3D Mockup Studio

Распакуйте архив. Загрузите содержимое в корень репозитория: index.html должен быть в корне. Включите GitHub Pages для выбранной ветки и корневой папки.

Не запускайте index.html двойным кликом: модулям нужен HTTP-сервер или хостинг. Для 3D требуется WebGL.
Удаление фона работает для однотонного фона. 3D-модели упрощённые.
